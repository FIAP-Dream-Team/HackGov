# Triage Labels

As skills do Matt falam em cinco papéis canônicos de triage. Neste repo esses nomes são **vocabulário
interno da skill**, não labels que já existem no Linear.

| Label in mattpocock/skills | Label no Linear hoje | Meaning |
| -------------------------- | -------------------- | ------- |
| `needs-triage` | _(não criada)_ | Mantenedor ainda precisa avaliar |
| `needs-info` | _(não criada)_ | Esperando informação de quem reportou |
| `ready-for-agent` | _(não criada)_ | Pronta para agente trabalhar |
| `ready-for-human` | _(não criada)_ | Exige implementação humana |
| `wontfix` | _(não criada)_ | Não será feito |

## Regra HackGov

1. **Não crie** essas labels automaticamente no Linear.
2. Enquanto elas não existirem no time, a skill `triage` classifica em **comentário no card** ou
   em texto local — sem chamar criação de label.
3. Se o grupo quiser as cinco labels de verdade, a decisão entra em `docs/decisoes.md` e alguém
   cria no time `Dream Team` antes de a skill aplicá-las.
4. Labels de Cap 1 (`documentacao`, `requisitos`, etc.), quando existirem, são ortogonais a estes
   papéis: tipo de entregável ≠ estágio de triage.
